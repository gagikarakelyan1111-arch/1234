# Эхо-Бездна (Fabric, Minecraft 26.2)

Версия 0.1: механика звука. Громкие действия создают волну частиц, а монстры рядом идут на шум.

- Добыча блока: шум в радиусе 20 блоков. Шерсть глушит (радиус 4).
- Бег: шум в радиусе 12 блоков раз в секунду. На шерсти и при ходьбе/подкрадывании тихо.
- Монстры, у которых уже есть цель, на шум не реагируют.

Настройки лежат в начале `src/main/java/com/echoabyss/EchoAbyss.java`.

## Как получить мод (.jar)
1. Создай репозиторий на GitHub и загрузи в него все файлы этого проекта (включая скрытую папку `.github`).
2. Открой вкладку **Actions**: сборка запустится сама (или нажми Run workflow).
3. Когда она станет зелёной, открой её и внизу в **Artifacts** скачай `echo-abyss-jar`.
4. Распакуй zip, положи файл `echo-abyss-0.1.0.jar` (не `-sources`) в папку `mods` и поставь Fabric API.

Нужны: Minecraft 26.2, Fabric Loader 0.19.3+, Fabric API, Java 25.
